# inventory_app
Inventory App — веб-застосунок для обліку товарів на складі, розроблений у межах модульної / контрольної роботи.

Функціонал
Додавання, перегляд, редагування та видалення товарів (CRUD)
Пошук і фільтрація товарів (AJAX + JSON)
Робота з базою даних MySQL через PDO
Захист від SQL-інʼєкцій, XSS та CSRF
Охайний інтерфейс користувача

Технології
PHP 8
MySQL / MariaDB
HTML, CSS
JavaScript (Fetch API)
XAMPP

Запуск
Імпортувати Database.sql у phpMyAdmin
Перевірити налаштування в db.php
Відкрити: http://localhost/inventory_app/

Структура БД
Таблиця items: id, name, category, price, quantity, created_at
